# Pixel Agent Garden — UI 与功能总览

> 这份文档详细描述**当前(2D 侧视版)**的画面构成、数据→视觉映射、各元素与解锁条件、以及界面控件。
> 用途:① 给设计/原型工具(如 2.5D 重设计)当参考;② 新人快速理解产品形态。
> 架构/数据流/adapter 细节见 [11-tauri-rust-rewrite-spec.md](./11-tauri-rust-rewrite-spec.md) 与 [architecture.md](./architecture.md);本文只讲 **UI 与功能**。

---

## 1. 一句话

把本机 AI 编程 agent(Claude Code / Cowork / Codex …)消耗的 **token 用量**,实时可视化成一座**会生长的像素中/日式庭院**。完全本地、零网络、不写源目录。

本质是一个**"数据仪表盘的拟物外壳"**:庭院好看之外,必须能让人一眼看出「有多少项目、谁最活跃、最近用得多不多」。

---

## 2. 画面整体构成

当前是**横版、单屏、静态**的场景(设计坐标 **680 × 440**,约 16:10),**纯侧视立面**——不滚动、不是俯视地图。像素艺术风,暖色调,cozy / storybook,中式 + 日式混搭的东亚庭院。

从后到前(z 由低到高)分层:

| 层 | 内容 |
|---|---|
| 天空带(y 0–110) | 天空渐变、云、太阳/月亮、远山(两层视差)、白天的飞鸟与蝴蝶 |
| 砖墙(y 110–380) | 程序化像素砖墙;**墙上挂满"项目藤"= 核心数据展示**;墙顶一圈常春藤覆盖 |
| 庭院地面(y 380–440) | 季节草地 + 石板路 + 各种物件 + 锦鲤池 + 会走动的猫 + 季节粒子 |
| 叠加 UI(HTML 层) | 顶部 header、hover 信息卡、底部工具条、各种面板 |

> 墙与石板路目前是**程序化生成的像素 tile**(`web/scene-tiles.js` 的 SVG `<pattern>` + 随机风化叠加),不是图片素材;其余物件是 PNG sprite。

---

## 3. 数据 → 视觉映射(产品灵魂)

| 数据来源 | 视觉表现 |
|---|---|
| **每个 agent 项目** | 墙上一条**藤蔓**(hanging 垂挂 / climbing 攀爬) |
| 项目 token 量 | 藤越大、越茂密(分多个 size level) |
| 项目**来源** | 藤色调:Claude Code 偏暖绿、Codex 偏冷蓝绿(-28° 色相)、混合居中 |
| 项目 cache 命中率 | 藤的"健康"色(命中高→更鲜绿) |
| 项目最近活跃度 | 越活跃越鲜绿;久未动偏枯 |
| **总 token** | 解锁/升级:凉亭大小、亭内陈设(trinkets)、终极解锁会走动的猫 |
| **总 sessions** | 招财猫石像、石塔的等级 |
| 总 recent_activity | 樱花开放程度(花苞→盛开→落英) |
| 今日是否有活动 | 石灯笼是否点亮 |
| 季节(系统/手动) | 全局配色 + 粒子 + 樱/枫/雪 |
| 时段(系统/手动) | 天空、光照、昼夜专属生物 |

## 4. 元素详解(含解锁/分级阈值)

### 4.1 项目藤(画面信息核心)
- 每个被扫描到的 agent 项目 = 一条藤,挂在砖墙上。墙面应**挂满几十条**,密度即信息量。
- 形态:`hanging`(从墙上垂挂)与 `climbing`(从地面向上爬)。
- 大小:按项目 token 分级(`size_level` / `size_strength`),小项目是细小新芽,大项目繁茂下垂。
- 颜色:`vineHueShift` 按来源——claude-code `0°`(绿)、codex `-28°`(冷蓝绿)、其它来源 `+14°`(略暖),混合按比例。
- 健康度:按 `cache_ratio` 做饱和/亮度微调。
- 交互:**hover / 聚焦某条藤 → 弹出项目信息卡**(见 §5.2)。轻微随风摆动动画。

### 4.2 凉亭(pavilion)与亭内陈设
- 中式凉亭,按**单项目最大 token** 分三级:`full` ≥ 100M、`mid` ≥ 10M、否则 `small`。
- 亭内地面陈设(按"最大项目阶段 stage 1–6"解锁):
  - 矮木桌(`stage ≥ 3`)、坐垫(`stage ≥ 4`)。
- **亭内 trinkets**(按**总 token** 解锁,挂檐/摆放):
  - 挂卷 `1M` · 茶具 `10M` · 风铃 `50M` · 香炉 `100M` · 睡猫(隐藏终极)`500M`。

### 4.3 树木
- **垂柳** willow:`young` / `mature`(`mature` = 总 token ≥ 10M **或** 项目数 ≥ 5)。庭院里最大的树。
- **樱花** cherry:按总 recent_activity 分 `bud`(花苞) / `bloom`(盛开,≥ 15k) / `petal`(落英,≥ 100k);盛开时伴随飘落花瓣。
- **竹丛** bamboo:墙角一小片(3 簇,前中后景)。

### 4.4 石器(石组造景)
- **招财猫石像** stone_cat:按**总 sessions** 分 `full` ≥ 20 / `small` ≥ 4 / 低于则隐藏。hover 显示"镇园守护"信息。
- **石灯笼** stone_lantern:`lit` / `unlit`——今日有活动、或黄昏/夜晚时点亮(暖光呼吸动画)。
- **石塔** stone_cairn:多层叠石,等级随招财猫(sessions)。
- **石器组**:石灯笼 + 石塔目前并排在石猫与垂柳之间的"石径"上(同视角、同石质主题)。

### 4.5 锦鲤池(koi pond)
- 凉亭前的水景(经典"水榭"位),常驻。
- 因为整体是纯侧视,而池子本质是俯视水面,目前做了**竖直压扁**处理使其呈"低角度浅池"以减少违和(这正是想改 2.5D 的动机之一——等距下水池会彻底自然)。

### 4.6 会走动的猫(garden cat)
- **总 token ≥ 500M 解锁**的"住客"。
- JS 状态机驱动漫步:在庭院草地一条带内随机选目的地(偏好几个"习惯点"+ 短距巡逻),变速行走、转身、随机停顿(歇/坐/理毛),步频随速度,近大远小透视;尊重动效设置。

### 4.7 季节粒子 + 天空生物
- 季节:春落樱、夏萤火虫(夜晚)、秋枫叶、冬雪。
- 天空(白天/黄昏):云、飞鸟、蝴蝶(均为 PixelLab 像素 sprite,夜晚不出现——夜晚归星星与萤火虫)。

### 4.8 地面
- 草地:颜色随季节;石板路 tile(程序化);可选 flowerbed 花床模式(铺真实花 sprite)或简化散花。

## 5. 界面控件与面板(HTML 叠加层)

### 5.1 顶部 header
- 左:应用标题 + 当前总 token。
- 右:实时 meta——「季节 · 节气」「时段 · 时间」(24 节气、昼夜)。

### 5.2 项目信息卡(hover 浮卡)
hover 藤/石猫时弹出:项目名、总 token、阶段、来源占比、最近活跃(相对时间)、缓存命中率、近期 token 走势 **sparkline**。

### 5.3 底部工具条 footer
- 数据新鲜度("更新于 X 前" / 扫描中 / 已缓存)、隐私标语("仅取本机 agent 数据 · 零网络请求")。
- 按钮:**明信片**导出、**Insight** 面板、**Dashboard**、设置齿轮。

### 5.4 Insight 面板
- 全部项目列表(不止 top 10):搜索框(按名/路径/来源/模型过滤)、"显示全部 / 收起"切换、每行 sparkline,按 token 排序;点击某行高亮对应墙藤。

### 5.5 设置面板(footer 内嵌展开)
- 外观:季节(system/四季)、时段(system/昼/暮/夜)、动效(system/reduced/off)、花床开关等。
- 数据:auto_rescan 开关等。改动防抖写盘,实时重绘场景。

### 5.6 明信片导出
- 把当前庭院导出成**可分享 PNG**:像素边框 + 右上季节"邮票" + 圆形"邮戳"(LOCAL AGENT GARDEN + 日期) + 底部两行说明(季节·时段 / 藤数·token·可选项目名)。
- 面板内**实时预览**,可勾选是否含项目名(默认匿名,绝不输出本地路径),确认后原生保存。

### 5.7 错误 toast
- 右下角非阻塞提示(扫描/设置失败等)。

## 6. 季节 / 日夜系统

- **四季**:春/夏/秋/冬——驱动草地与花的配色、季节粒子、樱花/枫叶/雪、以及对 sprite 的统一色调微调。
- **昼夜**:白天(蓝天、云、鸟、蝶、亮)、黄昏(粉橙、暖、太阳低垂)、夜晚(深蓝、星星、萤火虫、月亮、灯笼亮)。
- 默认跟随系统时间/月份,可在设置里手动锁定。

---

## 7. 技术与约束(设计/原型需要知道)

- **画幅**:横版单屏静态(约 680×440 / 16:10),非滚动、非俯视地图。当前为**纯侧视立面**。
- **风格**:像素艺术,暖色 cozy,中 + 日混搭东亚庭院;现有凉亭/垂柳/石灯笼/锦鲤等素材已是较精致的像素美术,任何新素材需匹配其精致度与配色。
- **渲染**:前端是无构建的原生 ES module + SVG/Canvas(无打包器、无第三方运行时);墙/路是程序化 `<pattern>`,物件是 PNG sprite(`assets/sprites/`)。
- **隐私**:绝对零网络、不写源目录、本地缓存;明信片等导出默认匿名。
- **国际化**:全 UI 中英双语。
