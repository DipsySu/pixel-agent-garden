The contract

Local files become garden growth, nothing leaves your machine.

Pixel Agent Garden normalizes each source into the same Rust event model, then renders the result as a quiet courtyard, CLI wall, tray watcher, share cards, and local cost estimates.

Wall mode

A brick wall for vines, stickers, and project memory.

The Wall view keeps the original visual metaphor visible: project growth hangs from the wall edge, programming stickers mark the ecosystems around the work, and the wall surface becomes a direct map of local agent activity.

What it does

A garden, not another dashboard.

The app still gives you numbers when you ask for them, but the primary surface is ambient: glance at the garden, see what grew, then return to work.

01

Living courtyard

Tokens, sessions, cache activity, recent work, time, and season shape vines, lights, cats, trees, and pavilion details.

02

Multi-agent adapters

Claude Code, Claude Cowork, Codex, and manual JSONL normalize into one core model, with future adapters kept isolated.

03

Local insight drawer

Inspect projects, model composition, daily activity, estimates, and history without sending data to a server.

04

Cost estimates

Model pricing lives locally. Split input, output, cache read, and cache write tokens are priced when sources expose them.

05

Share cards

Export a garden postcard, weekly recap, or year review as local images, with private paths filtered out.

Tray and CLI

Keep the garden in the desktop tray, run scans on demand, or use the terminal wall and usage commands directly.

Install

Download the desktop app, or build it from source.

Releases include macOS, Windows, and Linux builds. The project is still local-first even when built from source: no npm install, no CDN, no runtime telemetry.

Privacy boundary

Designed so you can verify the promise.

The privacy story is not a marketing footer. It is the architecture: source adapters read, core aggregates, UI renders, and state stays in the local garden directory.

No scan/render network clients The app does not need a server to turn local agent traces into the garden.
No telemetry pipeline No analytics events, remote crash reports, or hidden usage logging.
Read-only source directories Claude and Codex data are inputs, never mutation targets.
Inspectable local state Cache, settings, prices, and memory files live under ~/.local-agent-garden/.
