## Accepted Scope Clarifications

The PRD file is a living product plan and still contains some early wording
around tray menu entry points. The shipped v2.0 interaction model is:

- Weekly / Seasonal / Year artifacts live in the Share drawer.
- Scene banners are the automatic ritual entry point.
- Native tray remains the watch/scan/top-project system surface.
- Year Review exports the complete five-card set as one long PNG. Per-card
  export can be added later if users ask for it.

This matches the latest roadmap and changelog wording. It is not treated as a
release blocker for `v2.0.0`.
